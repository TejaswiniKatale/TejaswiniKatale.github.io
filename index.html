Recent Projects

CVaR-Aware Evolutionary Game for VANET Attack-Defense under Traffic Uncertainty
Research project on cyber-physical transportation security, traffic simulation, and risk-aware game modeling

This project develops a three-layer data-to-game framework that connects traffic simulation, cyber attack-defense modeling, and CVaR-aware evolutionary games for VANET security. The system evaluates how cyber attacks such as false congestion messages, Sybil reports, jamming, and packet loss can affect traffic performance, delay, throughput, and safety.

The framework models defense strategies such as source consistency checks, reputation thresholds, authentication, redundancy, and channel hopping. By using repeated simulation runs and loss distributions, the project focuses not only on average outcomes but also on worst-case risks through Conditional Value-at-Risk.

VANET Security Cyber-Physical Systems Evolutionary Game Theory CVaR Risk Modeling Traffic Simulation
Reinforcement Learning for Adaptive Traffic Signal Control using SUMO and TraCI
Research project on intelligent transportation systems and AI-based traffic control

This project explores reinforcement learning methods for adaptive traffic signal control using SUMO and TraCI. The goal is to design traffic signal policies that can improve mobility under changing traffic demand, connected vehicle penetration rates, and congestion conditions.

The work compares learning-based and rule-based signal control strategies, including DQN, Double DQN, Dueling Double DQN, Self-Organizing Traffic Lights, and Max Pressure control. The system evaluates performance using measures such as delay, throughput, reward, queue behavior, and emergency vehicle travel delay.

Gasoline Prices and Transit Ridership: Evidence from 50 U.S. Transit Agencies, 2002–2026
Bo Chen, Tejaswini Katale, Lu Gao
Transportation Research Record (Accepted), 2026
This study examines how gasoline prices are associated with public transit ridership using monthly panel data from 50 U.S. transit agencies. It finds that higher gasoline prices are linked to increased transit use, with stronger effects for rail than for bus ridership.
